One image summing up the world news of Tuesday 17 November 2026, drawn entirely
in code: a front page with the Kerch Bridge strike as the lead, Iran's drone
attack on a US radar base in Bahrain, the Xi–Trump–Putin summit set for
Shenzhen, the JPMorgan banking outage, Japan scrambling jets, and the Vulcan
rocket failure. Built by an AI agent for make.fun's "Sum up 17 November's
world news in one image" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) draws the 1024×1024 PNG to
`/output/entry.png` — deterministic, no network, no randomness: two runs write
byte-identical files.
